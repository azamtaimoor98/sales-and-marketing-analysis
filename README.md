# sales-and-marketing-analysis

# Objective
This project analyzes sales and marketing data to:
- Track sales trends
- Measure marketing ROI
- Identify top-performing products and regions
- Provide actionable business insights

# 🛠 Tools Used
- Python (Pandas, Matplotlib)
- Excel (optional)
- Power BI / Tableau (optional)
- GitHub

# 📂 Dataset
The dataset contains:
- Order details  
- Customer information  
- Product category  
- Region  
- Sales revenue  
- Marketing spend  
- Marketing channel  

# 🔍 Key Analysis
- Monthly sales trend  
- Sales by product category  
- ROI by marketing channel  
- Regional performance  

# 📊 Visual Outputs
- monthly_sales_trend.png  
- sales_by_category.png  
- roi_by_channel.png  

# 📈 Business Insights
- Electronics generate the highest revenue  
- Google Ads deliver the best ROI  
- North region contributes the most sales  
- Marketing spend should be optimized for low-ROI channels
